# Selling History

The Selling History page shows a complete record of all completed sales transactions.

---

## What You'll See

The table displays:

| Column | Description |
|--------|-------------|
| **Code** | Unique transaction identifier |
| **Cashier** | The user who processed the sale |
| **Member** | The member associated with the sale (if any) |
| **Customer Number** | Customer reference number |
| **Date** | When the transaction occurred |
| **Grand Total** | Final amount after tax and discounts |
| **Total** | Subtotal before tax |
| **Tax** | Tax amount applied |
| **Cost** | Total cost of items sold |

---

## Filtering

You can narrow results using:

- **Cashier filter**: Show sales from a specific cashier.
- **Date range**: Filter sales by a custom date range.

---

## Viewing a Sale

Click on any sale to view the full details, including:

- Individual line items and quantities
- Payment method used
- Refund history (if applicable)
- Option to **Send as Invoice** or **Issue Refund**

---

## Tips

- Use the Selling History to reconcile daily sales with your Z-Report.
- If you need to issue a refund, open the sale and use the **Issue Refund** button at the top. If **Refunds** is ticked under Manager Override Codes, the refund form also asks for a manager PIN. See [Manager Override Codes](./setting/manager-override.md).
